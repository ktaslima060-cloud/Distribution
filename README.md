# Distribution: Normal & Standard Normal Distribution

A comprehensive Python project exploring the fundamental principles, visual representations, and practical applications of **Normal Distribution (ND)** and **Standard Normal Distribution (SND)** in data science and statistics.

---

## 📌 Project Overview

This repository focuses on continuous probability distributions, statistical normalization, and empirical analysis using standard Python data science libraries.

### Key Concepts Covered
* **Normal Distribution ($\mu, \sigma$):** Explores Probability Density Functions (PDF), Cumulative Distribution Functions (CDF), and standard deviation variations ($\sigma$) across bell curves.
* **Standard Normal Distribution ($\mu = 0, \sigma = 1$):** Demonstrates data standardization via $Z$-score transformation:
  $$Z = \frac{X - \mu}{\sigma}$$
* **Statistical Computation:** Programmatically calculates probability ranges, percentiles, confidence intervals, and $Z$-score evaluations.
